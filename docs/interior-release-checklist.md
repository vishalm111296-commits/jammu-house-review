# Interior viewer release checklist
Status: Proposed workflow; no application changes in this update.

The private project holds detailed design records. This public repository receives only reviewed releases and material explicitly selected for public sharing.

## Release sequence
1. Resolve design decisions in the private master.
2. Implement and test changes there.
3. Build a single offline HTML with embedded permitted assets.
4. Review the public package for personal data and image permissions.
5. Publish selected build with version, checksum, change log and test evidence.

## Required checks
- Phone and desktop screenshots before/after changes.
- Visible room-specific colour and whole-house scheme controls.
- Doors, curtains, fan, lighting and camera controls respond.
- Reduced-motion preference and explicit override work.
- Photo save/reload/export/delete/Undo and storage failure handling.
- No console errors, missing assets or runtime network dependency.
- Clear distinction between real user photographs, licensed imagery and AI concepts.
- Unconfirmed design choices remain provisional; no invented product codes, prices or measured dimensions.
- Physical Android test reported separately from browser emulation.

This checklist introduces no house measurements, site photographs, private design records or working application features. No fresh runtime test is claimed.
